Alya — Privacy Policy

Last updated: 2026-09-18 · Applies to Alya for Windows (all distribution channels)

Summary

Alya does not collect, transmit, or sell any personal data. There are no accounts, no telemetry, no analytics and no advertising in the app.

What the app stores on your device

  • Settings (interface language, hotkeys, theme, translation preferences) are stored locally on your device.
  • API credentials: the API key you provide is encrypted with Windows DPAPI (bound to your Windows user account) and stored locally. It is never included in any diagnostic output.

What leaves your device

When you trigger a translation, the selected source text is sent — over an encrypted connection — to the AI service endpoint you configure (for example DeepSeek or another OpenAI-compatible provider), using the API key you supply. The developer does not operate, proxy, or log this traffic. Screenshot text recognition (OCR) is performed locally on your device; the screenshot itself is never uploaded.

Crash reports

Alya does not submit crash reports. If you choose to report a bug, you decide what to include.

Contact

Open an issue at the project's GitHub repository or use the support contact listed on the store page.

Alya — 隐私政策

更新日期：2026-09-18 · 适用于 Windows 版 Alya（所有分发渠道）

摘要

Alya 不收集、不传输、不出售任何个人数据。应用内没有账号体系、遥测、分析统计或广告。

应用在你设备上存储的内容

  • 设置（界面语言、快捷键、主题、翻译偏好）仅保存在你的设备本地。
  • API 凭据：你提供的 API Key 经 Windows DPAPI 加密（绑定你的 Windows 账户）后本地存储，不会出现在任何诊断输出中。

离开你设备的内容

当你触发翻译时，所选原文会通过加密连接发送到你自己配置的 AI 服务端点 （例如 DeepSeek 或其他 OpenAI 兼容服务商），使用你自己的 API Key。开发者不经手、 不代理、不记录该流量。截图文字识别（OCR）在本机完成，截图本身不会上传。

崩溃报告

Alya 不提交崩溃报告。如你主动反馈问题，包含哪些内容由你决定。

联系方式

请通过项目 GitHub 仓库提交 Issue，或使用商店页面列出的支持联系方式。
