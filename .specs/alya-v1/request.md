## 原始请求

用户要求实现一个可跨软件翻译的 Windows 桌面应用（参考 pot-desktop），功能包含：

1. 划词翻译（跨软件）：选中任意软件中的文本，按快捷键弹出翻译。
2. 输入翻译：快捷键呼出翻译窗口，输入文本回车翻译。
3. 剪贴板监听模式：面板左上角开关开启后，复制即翻译。
4. 截图 OCR：快捷键框选屏幕区域，识别文字。
5. 截图翻译：快捷键框选屏幕区域，直接出译文。

约束：仅接 AI 翻译，现阶段只接 DeepSeek API；界面简洁美观大方；按软件工程流程交付（需求→设计→开发→测试→发布）。已通过 grill-with-docs 完成需求对齐。

## 澄清结果（与用户逐题确认，2026-08-26）

1. 技术路线：全新 Tauri 2 应用，借鉴 pot 已验证机制；不 fork（GPL-3.0 规避 + Tauri 1.x 已停维护），见 docs/adr/0001。
2. 翻译场景：双场景模型——**互译**（中文→英文、非中文→中文，提示词固定）与**定向**（译向指定目标语言，{{target}} 模板）；全局唯一活动场景持久化，默认互译；界面一键切换 + 全局热键切换。
3. 定向目标语言：设置页默认值（默认英文），翻译面板下拉临时切换。
4. 产品名：Alya。
5. AI 接入：出厂默认 DeepSeek 官方（https://api.deepseek.com + deepseek-chat），接口地址/模型名/API Key 可配置，兼容 OpenAI 兼容协议；流式调用。
6. 运行形态：托盘常驻无主窗口、单实例、首次运行引导配置 API Key（含"原文发送至云端"隐私告知）。
7. 面板行为：失焦即隐（设置可关）；译文呈现三档可配（全部流式 / 短文流式+长文整段[阈值可配]，整段模式需等待动效+预估剩余时间）；原文可编辑重译；尺寸可调且记忆。
8. 截图链路：松开鼠标即确认框选；全屏暗色遮罩高亮选区；多显示器独立框选；放大镜/像素拾取器 v1 不做。OCR 语种：默认自动（系统首选语言），设置页可固定语种，识别面板提供语种下拉重新识别；未装语言包时报错并给官方指引链接。OCR 采用 Windows.Media.Ocr（离线系统引擎）。
9. 快捷键出厂默认（用户未答复，按推荐执行，PRD 评审可推翻）：划词 Alt+Q、输入 Alt+E、截图识别 Alt+S、截图翻译 Alt+D、切换场景 Alt+W、剪贴板监听不设热键（面板开关+托盘开关）；全部可在设置改键；注册冲突时系统通知告知。
10. 发布形态（用户未答复，按推荐执行）：NSIS 安装包（x64）+ 便携版 zip；v1 无自动更新。

主 Agent 补充并待评审确认的默认约定：v1 界面仅简体中文；主题亮/暗/跟随系统；托盘右键菜单聚合各功能；API Key 本地加密存储（倾向 Windows DPAPI）；互译提示词采用用户提供的原文模板。
