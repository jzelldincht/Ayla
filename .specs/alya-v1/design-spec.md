## 0. 适用范围与约束

- 本规范定义 Alya v1 的**视觉与交互契约**：信息架构、布局、状态、文案、动效、无障碍。不包含实现代码，不指定前端框架与组件库（由架构师决定）；实现方在不违反本文档的前提下自选实现手段。
- 严格遵循 CONTEXT.md 术语：互译、定向、活动场景、目标语言、划词翻译、取词、输入翻译、剪贴板监听、截图识别、截图翻译、**翻译面板**。界面文案禁止出现"智能翻译""自动模式""指定翻译""截图取词"等被规避词；"翻译面板"不写作"弹窗/翻译窗"。
- 所有尺寸均为**逻辑像素（DIP）**，随系统 DPI 缩放；特别标注"物理像素"的除外。
- 界面语言仅简体中文（FR-1.1）。
- 参考物 pot-desktop 仅用于信息组织借鉴，禁止复用任何视觉资产与代码（ADR-0001）。

## 1. 设计原则

| 编号 | 原则 | 可执行判据 |
|---|---|---|
| P1 | **一眼即得译文** | 从触发到看见译文，路径上不允许出现任何多余确认步骤；译文区是面板的视觉重心（占据剩余全部高度），原文区让位于译文区 |
| P2 | **单列信息流** | 所有形态一律"上文下单"纵向单列，不做左右分栏、标签页或多列卡片；每个形态只回答一个问题（译什么 / 输入了什么 / 识别出了什么） |
| P3 | **克制的色彩** | 约 95% 界面面积为中性色；主色仅用于可交互元素与选中态；语义色（成功/警告/错误）仅在对应状态出现；无装饰性渐变、插画、大面积色块 |
| P4 | **安静的动效** | 动效只表达因果关系（从哪来、正在发生、已完成），时长 120–260ms；禁止弹跳、回弹、纯装饰循环动画（唯一例外：等待指示） |
| P5 | **暗色为一等公民** | 亮/暗两套主题同批设计、同批验收，暗色为独立校准的配色而非亮色反相；出厂"跟随系统"（FR-1.2） |

## 2. 视觉语言

### 2.1 Design Tokens（亮 / 暗）

> 数值为基线值；实现可在满足第 10 章对比度底线的前提下做 ±5% 明度微调，色相不变。

**中性色**

| Token | 亮色值 | 暗色值 | 用途 |
|---|---|---|---|
| `bg/base` | `#FFFFFF` | `#1F232A` | 面板、窗口底层背景 |
| `bg/subtle` | `#F5F7FA` | `#262B34` | 只读原文区底、设置分组底、输入框底 |
| `bg/hover` | `#EDF1F6` | `#2E343E` | 列表行、图标按钮悬停 |
| `bg/active` | `#E3E9F2` | `#37404C` | 按下态 |
| `fg/title` | `#17202E` | `#EEF2F7` | 标题、重点文本 |
| `fg/body` | `#38414F` | `#C6CDD8` | 正文（原文/译文/识别文本） |
| `fg/muted` | `#5F6877` | `#8D97A5` | 辅助说明、占位符、标签 |
| `fg/disabled` | `#A6ADB9` | `#5C6572` | 禁用文本 |
| `border/subtle` | `#E6EAF0` | `#333A44` | 分隔线、输入框描边常态 |
| `border/strong` | `#CBD3DE` | `#47505D` | 输入框聚焦外沿以外的强描边、拖拽把手 |

**品牌与语义色**

| Token | 亮色值 | 暗色值 | 用途 |
|---|---|---|---|
| `accent/primary` | `#2E63DC` | `#6E97F0` | 主色：主按钮、选中态、链接、选区边框、焦点环 |
| `accent/primary-hover` | `#2453C4` | `#86A9F4` | 主色悬停 |
| `accent/primary-active` | `#1E46AC` | `#9BBBF7` | 主色按下 |

气质定位：中性冷灰底 + 一个沉稳的钴蓝主色，整体安静、克制、工具感，无娱乐化倾向。

### 2.2 字体与字号阶梯

**字体栈（中文优先）：**
`"Microsoft YaHei UI", "Microsoft YaHei", "Segoe UI", system-ui, sans-serif`

- 界面全部文字走此栈；不引入外部字体文件。
- 等宽数字场景（预估剩余时间、选区尺寸标签）：优先对该元素启用数字等宽特性（tabular figures），兜底栈 `"Consolas", monospace`。

**字号阶梯：**

| 层级 | 字号/行高 | 用途 |
|---|---|---|
| `display` | 20px / 28px | 引导页标题 |
| `title` | 16px / 24px | 设置分组标题、引导正文标题 |
| `body` | 14px / 22px | 原文、译文、识别文本、设置行标签（默认层级） |
| `secondary` | 13px / 20px | 辅助说明、设置项描述、下拉选项 |
| `caption` | 12px / 18px | 时间徽标、尺寸标签、占位符、快捷键提示 |

- 原文与译文同为 `body`，不做大小区分，以区块位置与标签区分主次（P1/P2）。
- 最小可读字号 12px，不再往下。

### 2.3 间距体系（4px 基数）

| Token | 值 | 用途 |
|---|---|---|
| `space-1` | 4px | 图标与文字间距、紧凑内边距 |
| `space-2` | 8px | 相关控件间距、区块内行距 |
| `space-3` | 12px | 区块与标题间距 |
| `space-4` | 16px | 面板四周内边距、卡片内边距 |
| `space-5` | 24px | 大区块分隔（设置分组间、引导段落间） |
| `space-6` | 32px | 引导页上下留白 |

关键尺寸：顶栏高 44px；面板内容左右内边距 16px；图标按钮命中区 28×28；设置行高 40px；按钮高 28px（面板内）/ 32px（设置与引导）。

### 2.4 圆角与阴影

| Token | 值 | 用途 |
|---|---|---|
| `radius-window` | 10px | 翻译面板、引导窗体外轮廓 |
| `radius-control` | 6px | 按钮、输入框、分段控件、下拉 |
| `radius-card` | 8px | 错误卡片、隐私告知强调块 |
| `radius-pill` | 全圆角 | 尺寸标签、预估时间徽标 |

阴影（两档，暗色主题透明度上调约 1.4 倍）：

| Token | 亮色值 |
|---|---|
| `shadow/panel` | `0 8px 28px rgba(0,0,0,0.18), 0 2px 8px rgba(0,0,0,0.10)` |
| `shadow/popover` | `0 4px 16px rgba(0,0,0,0.14)` |

面板与引导窗体必须带 `shadow/panel`；下拉菜单、托盘外的浮动元素用 `shadow/popover`。

### 2.5 动效

统一缓动：入场 `cubic-bezier(0.2, 0, 0, 1)`；出场 `cubic-bezier(0.4, 0, 1, 1)`。

| 场景 | 时长 | 表现 |
|---|---|---|
| 面板弹出 | 160ms | 透明度 0→1 + 上移消失的逆过程：`translateY(4px)→0` + `scale(0.98)→1` |
| 失焦隐没 / 关闭隐藏 | 120ms | 透明度 1→0，位移不变（快速、不抢注意力） |
| 分段控件选中滑块 | 120ms | 选中底色块平移至目标段 |
| 目标语言下拉展开 | 140ms | 透明度 + `translateY(-2px)→0` |
| 流式增量追加 | ≤90ms/次 | 仅对新追加的文字片段做透明度淡入；禁止整段重绘、闪烁（FR-10.4） |
| 流式光标条 | 持续闪烁周期约 1s | 译文末尾 2px 竖条，完成后 200ms 淡出 |
| 等待指示（呼吸圆点） | 1.2s 循环 | 三枚圆点依次起伏，幅度克制（透明度 0.35→1） |
| 预估剩余时间刷新 | 每 1s | 数值直接替换，不加动画（避免数字滚动噪音） |
| 错误卡片出现 | 140ms | 透明度 + `translateY(2px)→0` |
| 框选遮罩淡入 / Esc 退出 | 100ms / 150ms | 见第 6 章 |
| 引导分步切换 | 200ms | 内容区按前进/后退方向水平滑动 |

减弱动效：当系统关闭动画效果时，所有位移类动效取消，仅保留 ≤80ms 的透明度过渡；等待呼吸点退化为静态"翻译中…"文字 + 不确定细进度条。

## 3. 翻译面板（核心交付物）

### 3.1 总体结构与窗口规格

- 无边框自绘窗体：顶栏兼任拖拽移动区；四边与四角设 6px 拖拽调尺寸热区（FR-9.3）。
- **默认尺寸 460 × 340 逻辑像素；最小 360 × 240；上限为所在显示器工作区的 80%。**
- 尺寸记忆为**面板级单一尺寸**，四种形态共用一套记忆值（形态切换不重置尺寸）。
- 弹出瞬间置顶一次，不做常驻置顶；失焦行为遵循 FR-9.2（失焦即隐，可关）。
- 关闭按钮仅隐藏面板，应用驻留托盘（FR-1.3）。

### 3.2 顶栏（四形态共用骨架）

```text
┌────────────────────────────────────────────────────────┐
│ (监听) [互译 ▏定向]  {日文 ▾}            [×]           │ ← 高 44px，拖拽移动区
└────────────────────────────────────────────────────────┘
   │         │              │                 │
   │         │              │                 └─ 关闭：幽灵图标按钮 28×28，
   │         │              │                    悬停 bg/hover，永远可见（FR-9.2）
   │         │              └─ 目标语言下拉：仅定向形态出现，
   │         │                 出现/消失 140ms 过渡，紧跟分段控件右侧 8px
   │         └─ 活动场景分段控件：两段等宽，选中段 accent 底 + on-primary 文字；
   │            Alt+W 触发时选中滑块同步平移（FR-2.4）
   └─ 剪贴板监听开关（需求指定左上角第一位置）：
      图标式开关，关=fg/muted 线性图标，开=accent 填充图标；
      悬停 tooltip「开启后，自动翻译新复制的内容」
```

- 顶栏左侧簇：监听开关 → 分段控件 → （定向时）语言下拉；右侧簇：关闭按钮。中间为弹性空白。
- 分段控件旁常驻展示当前活动场景，即满足 FR-9.4"常驻展示 + 一键切换"。
- 语言下拉变更仅对下一次翻译生效，不回写设置默认值、不自动重译（FR-2.7）。
- 顶栏不放置其他入口（无设置齿轮、无历史），保持克制。

### 3.3 四种形态的信息架构与布局

#### 形态 A：翻译形态（互译 / 定向）——划词翻译、剪贴板监听的结果展示

```text
┌────────────────────────────────────────────────────────┐
│ (监听) [互译 ▏定向]                                     │
├────────────────────────────────────────────────────────┤
│ 原文                                        (12px 标签) │
│ The quick brown fox jumps over the lazy dog.           │
│                                                        │
├─ border/subtle ────────────────────────────────────────┤
│ 译文                                        (12px 标签) │
│ 敏捷的棕色狐狸跳过了懒惰的狗。▌                         │
│                                                        │
│                                                        │
└────────────────────────────────────────────────────────┘
```

- 原文区：**可编辑**（用户裁决 A1，2026-08-26）；内容被修改后右下角浮现「重译 ↵」主色小按钮（样式同形态 B 的「翻译」按钮），点击或在原文区内按 `Enter` 即以新原文重译、译文区进入新一轮等待态；未修改时不显示该按钮。文本始终可选中复制（原生选择 + Ctrl+C，见 13 章假设 A3）。高度按内容自适应，上限约为面板高度 40%，超出内部滚动。
- 译文区：占据剩余全部高度（P1），流式输出（FR-10.1"全部流式"模式）或等待后整段呈现（分档模式）。
- **互译与定向共用此布局，唯一差异**：定向时分段控件右侧出现目标语言下拉 `{日文 ▾}`（Q5 清单：中文(简体)、中文(繁体)、英文、日文、韩文、法文、德文、西班牙文、俄文）。
- 原文标签在定向时可附注目标语言，如「译文 · 日文」，增强方向感；互译时不注（界面不展示判向依据，符合非目标 11）。

#### 形态 B：输入模式形态——输入翻译入口（Alt+E / 托盘 / 二次启动唤起）

│ │                                       [ 翻译 ↵ ]   │ │ ← 主色小按钮，右下角
│ └────────────────────────────────────────────────────┘ │
├────────────────────────────────────────────────────────┤

- 翻译进行中再次提交：中止上一轮，仅呈现最新一轮（FR-9.6）。

#### 形态 C：截图识别结果形态——OCR 纯文字结果（不需要 API Key）

└────────────────────────────────────────────────────────┘

- **功能行**为本形态独有：
  - 语种下拉：选项为「自动」+ 系统 OCR 支持且已装语言包的语种；更换语种立即对原选区重新识别并更新文本（FR-6.2）。

- OCR 语言包缺失时，功能行下方出现错误横条（见 5.4 表，EX-6），流程终止、不发起翻译。

### 3.4 划词弹出的屏幕定位策略（FR-3.1 委托项）

适用：划词翻译与剪贴板监听的弹出（输入模式固定出现在上次位置附近即可，不适用本节翻转规则）。

1. **锚点**：触发时刻的鼠标指针位置。
2. **首选位**：锚点向右下偏移（+16px，+16px）处放置面板左上角。向下偏移使光标与选区行通常保持在面板上方，减少遮挡。
3. **选区避让（硬约束）**：若系统层能取得文本选区/光标的屏幕矩形，该矩形为禁区，面板不得与其相交；相交时先垂直翻转（放到选区下方再放上方），后水平翻转。无法取得选区矩形时，退化为第 2 条的鼠标锚点规则。
4. **防溢出翻转顺序**（以所在显示器工作区为界，工作区不含任务栏）：
   - 右溢出：改为面板右上角对齐锚点右侧（面板整体移到锚点左侧，偏移 −16px）；
   - 下溢出：改为面板底边在锚点上方（偏移 −16px）；
   - 角部同时溢出：双轴同时翻转；
   - 仍有溢出：向工作区内钳制，四周保留 8px 安全边距。
5. **多显示器归属**：面板始终归属于**锚点所在的那个显示器**，钳制与翻转都在该显示器工作区内完成，永不跨越显示器边界。
6. **DPI**：偏移量按逻辑像素定义，在各显示器各自的缩放系数下换算（验收 I4：100% / 150%）。

### 3.5 面板键盘契约

| 按键 | 行为 |
|---|---|
| `Esc` | 隐藏面板（任何形态、任何状态下均可用；进行中的翻译随之中止） |
| `Enter` | 形态 B 中提交翻译；形态 A / D 中焦点位于原文区且内容已修改时触发重译（同「重译」按钮） |
| `Shift+Enter` | 形态 B 中换行 |
| `Tab` | 按 3.2/3.3 各控件的视觉顺序流转：监听开关 → 互译 → 定向 → 语言下拉（若有）→ 关闭 → 原文区 → 翻译/送翻译按钮 → 译文区 |

## 4. 状态设计

### 4.1 状态矩阵（形态 × 状态）

| 状态 | A 翻译 | B 输入 | C 识别 | D 截图翻译 |
|---|---|---|---|---|
| 空态 | 不存在（必有原文） | 占位符 + 译文区空白引导语 | 识别中短暂等待 | 「未识别到文字」空态 |
| 等待（首字前） | 呼吸点 | 呼吸点 | —（本地 OCR，<1s 量级，仅瞬时忙碌指示） | 呼吸点 / 整段等待徽标 |
| 流式中 | 流式 + 光标条 | 流式 + 光标条 | — | 流式 + 光标条 |
| 完成 | 静态全文 | 静态全文 | 可编辑文本就绪 | 静态全文 |
| 错误 | 错误卡片 | 错误卡片 | 错误横条（EX-6） | 错误卡片 / 横条 |

### 4.2 空态

- 形态 B 初始：输入区占位符「输入要翻译的文本…」（fg/muted）；译文区显示引导语「译文会在这里出现」（fg/muted，居左上，非居中大插图——P3 克制）。
- 形态 D 空识别（FR-7.2）：原文区位置显示「未识别到文字」，副行「请调整选区后重试」；不渲染译文区，不发起请求。

### 4.3 等待与流式

**短文 / 流式模式（首字到达前）**：译文区左上角显示三枚呼吸圆点（2.5 节动效）；顶栏下方出现 2px 高不确定细进度条（accent 色，往复滑动），首字到达即移除。

**长文整段模式（FR-10.3）等待组件**：

```text
┌──────────────────────────────────────────────┐
│ 译文                      (◐ 预估剩余约 12 秒) │ ← 徽标：warning 色文字 +
│   ● ● ●                                      │    bg/subtle 胶囊底，
│   正在翻译长文本…                             │    12px 等宽数字
└──────────────────────────────────────────────┘
```

- 文案格式固定为「预估剩余约 N 秒」，N 为整数、每秒刷新；「预估」二字必须存在且与数字同级醒目，不得呈现为精确承诺（FR-10.3 / Q3 口径由实现层按已生成速率外推）。
- 已生成字符过少不足以估算速率时（实现层阈值），仅显示「正在翻译…」，不出示时间。
- 完成瞬间徽标淡出，整段译文以一次 140ms 淡入呈现。

**流式输出规则（FR-10.4）**：

- 增量追加渲染，每次追加片段 ≤90ms 淡入；末尾跟随闪烁光标条，完成后淡出。
- 滚动跟随：用户未向上滚动时自动贴底跟随；用户上滚超过一行高度即停止自动跟随，滚回底部后恢复跟随（不设悬浮按钮，P3 克制）。
- 流式中允许再次提交/触发（EX-13 中止语义），译文区清空进入新一轮等待态。

### 4.4 错误态（六类，对应 EX-1/2/3/4/5/14）

**错误卡片解剖**（置于译文区原位，非模态、不打断面板其余区域）：

```text
┌──────────────────────────────────────────────┐
│ ▍(!) 网络连接失败                             │ ← 左缘 3px error 竖条 +
│                                             │    error-bg 底 + radius-card
│   无法连接到翻译服务，请检查网络后重试。       │    说明文字 fg/muted
│                                [ 重试 ]      │    操作按钮：主色描边小按钮
└──────────────────────────────────────────────┘
```

| 类别 | 触发 | 标题（加粗） | 说明 | 操作按钮 |
|---|---|---|---|---|
| 网络 | EX-1 | 网络连接失败 | 无法连接到翻译服务，请检查网络后重试。 | 重试 |
| 鉴权 | EX-2 | 鉴权失败，请检查 API Key | API Key 无效或已被撤销。 | 打开设置（直达 AI 服务分组） |
| 余额 | EX-3 | 余额不足 | 账户余额不足，请前往服务商控制台处理后重试。 | 打开设置 |
| 超时 | EX-4 | 请求超时 | 服务 30 秒内未响应。 | 重试 |
| 传输中断 | EX-5 | （见 4.5，叠加于部分结果之后） | 连接中断，已保留部分译文。 | 重试 |
| 服务异常 | EX-14 | 翻译服务返回异常 | 服务端返回了无效响应，请稍后重试。 | 重试 |

- 「重试」= 以相同参数重新发起本轮完整翻译，替换当前错误卡片。
- 「打开设置」= 打开设置窗体并定位到 AI 服务分组。
- 错误态不自动重试、不无限等待（总原则）；错误卡片出现的同时译文区不再残留呼吸点或进度条。
- 附：OCR 语言包缺失（EX-6，形态 C/D）：错误横条「缺少 OCR 语言包」+ 说明「未安装“XX”语言包，无法识别该语种。」+ 文字链「查看微软官方指引」（外部浏览器打开）；流程就此停止，截图翻译场景同样不发翻译请求。
- 面板外系统通知文案（不自绘通知 UI，用系统 toast）：「未获取到选中文本」（FR-3.2/EX-10）；「未能获取文本」（FR-3.3）；「“XX”快捷键注册失败」（EX-7，XX 为功能名）。

### 4.5 传输中断的部分结果保留（EX-5）

```text
│ 敏捷的棕色狐狸跳过了懒惰……（已收到的部分，正常排版保留）│
│                                                      │
│ ▍(!) 传输中断                                         │
│     连接中断，已保留部分译文。            [ 重试 ]     │ ← 错误卡片紧随部分译文之后
```

- 已收到的部分译文以正常样式呈现，绝不删除、绝不置灰伪装成完整结果；紧随其后插入错误卡片。
- 「重试」重新发起**完整**翻译并替换全部内容（卡片说明不额外承诺续传）。
- 用户此时编辑原文重新提交（形态 B）同样成立，旧部分结果随新一轮请求清除。

各分组内容即 FR-13 表逐项落位（AI 服务 3 项 / 翻译 3 项 / 面板 2 项 / 快捷键 5 项 / 截图 1 项 / 通用 2 项），出厂默认值照抄需求表，此处不重复罗列。行模式：左侧标签（body）+ 描述（secondary, fg/muted），右侧控件；行高 40px，分组间 `space-5`。

### 7.2 快捷键录制控件（FR-14.2 / EX-7）

状态机：`展示态 → 录制态 → 校验 → 展示态（成功）| 展示态（回退）`

- 展示态：显示当前组合键（如 `Alt+Q`，键帽样式胶囊）+「修改」按钮。
- 录制态：控件变为「请按下新的快捷键…」；此时按 `Esc` 取消、点击控件外取消，均不改值。
- 录得新组合后立即"解旧注册新"：成功 → 更新键帽 + 「已保存」反馈；冲突/注册失败 → **自动回退原值** + 行内 error 提示「该快捷键已被其他程序占用，已恢复原快捷键」+ 系统通知指明功能名（EX-7）。
- 启动时即存在的冲突不在行内阻塞，但对应行尾常驻 warning 警示图标，悬停说明「注册失败，点击修改」。

### 7.3 API Key 掩码展示与修改流（需求第 7 章）

- 已存 Key 永远显示为固定 8 位掩码 `••••••••`（不反映真实长度），**任何视图不得明文回显**。
- 「修改」→ 该行进入编辑态：输入框清空、掩码录入，附录入期可见性切换（仅作用于正在输入、尚未保存的内容，与"回显已存 Key"无关）。「保存」即加密写入，「取消」放弃。
- 允许保存空值（表示未配置，回到掩码空态「未配置」文案）。

### 7.4 即时保存的反馈（FR-13 总则）

- 全页无「保存」按钮；任一控件变更即刻生效。
- 反馈方式：该行右端浮现 success 色「已保存」，1.5s 后淡出；仅失败项（如热键冲突）以 error 行内提示常驻直至解决。
- 主题项变更即时全窗生效，供用户直接预览（FR-1.2）。

| 项 | 要求 |
|---|---|
| 对比度底线 | 正文与译文 ≥ 4.5:1；≥18.66px 粗体大字与图形控件边界 ≥ 3:1；2.1 节基线值已按此校准，微调不得跌破 |
| 焦点可见 | 所有可交互元素获得键盘焦点时显示 2px `accent/primary` 外沿环（offset 1px，圆角随元素）；任何状态下不得移除焦点环 |
| 键盘可达 | 面板 `Esc` 关闭、`Tab` 序见 3.5；设置与引导全部控件可 Tab 到达、`Space`/`Enter` 激活；框选层 `Esc` 取消（FR-8.3） |
| 屏幕阅读器 | 图标按钮必须带可访问名称：监听开关="剪贴板监听"、关闭="关闭面板"、"送翻译"、"修改"等；状态型控件（监听开关、分段控件）播报开/关与选中态 |
| 动效偏好 | 遵循系统"动画效果"设置（2.5 节减弱动效规则） |
| DPI / 缩放 | 全部布局尺寸用逻辑像素；面板定位、框选遮罩坐标逐显示器按各自缩放换算；**150% 缩放下验收点（I4）**：面板不出屏、不与光标错位；框选遮罩与选区边框贴合像素；设置页 150% 下不出现横向滚动或控件截断；最小字号 12px 在 150% 下仍清晰 |
| 命中区 | 最小 28×28 逻辑像素（面板紧凑控件），设置页 32×32 |
