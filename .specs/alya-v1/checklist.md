## 0. 使用说明

- **分发规则**：requirements 第 8 章 A~K 共 52 条逐条映射、无遗漏——开发机无需用户特定环境即可验证的 16 条入「1 需求符合性」；其余 35 条入「6 真机矩阵」（QA 执行）；K3 落「5 发布物」。每条恰好一处承载。
- **依赖标注**（真机矩阵用；无标注＝任意 Win10/11 x64 真机即可）：【Key】需用户提供的 DeepSeek API Key（仅联调阶段注入，不落任何工件）；【硬件】多显示器 / DPI 缩放调整；【系统】系统重启 / 干净 VM / UAC / RDP / 密码重置流程；【外部】第三方热键占用程序 / 断网控制 / 语言包装卸 / 终端类应用 / 全屏游戏 / 杀软环境。

- 本清单只更新执行状态与证据；需求或范围变更须回上游工件，不得在本清单内改口径。
