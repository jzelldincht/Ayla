## 四、主要功能（申请表单「软件功能」栏，可直接粘贴）

```
Alya 智能翻译助手软件是一款运行于 Windows 的常驻型智能翻译工具，采用自带密钥方式接入兼容 OpenAI 协议的第三方人工智能翻译服务。主要功能包括：
1. 划词翻译：在任意应用中选中文字后通过全局快捷键呼出浮动面板并自动翻译；
2. 输入翻译：呼出输入面板输入或粘贴文本，支持停顿自动翻译与回车即时翻译；
3. 剪贴板监听翻译：可选功能，监听系统剪贴板并自动翻译新复制内容；
4. 截图识别：框选屏幕区域，在本机完成光学字符识别并输出可编辑文本；
5. 截图翻译：框选屏幕区域，本机识别后自动翻译，适用于字幕、游戏界面、图片等无法选中文字的场合；
6. 互译与定向双场景：互译自动判断翻译方向，定向固定输出目标语言并支持运行中切换语言即时重译；
7. 译文双呈现模式：全部流式输出与长文分档整段呈现（含预估剩余时间）；
8. 面板几何记忆：记忆窗口位置、尺寸与原文输入框高度，译文区随内容自动展开；
9. 多显示器与高 DPI 适配：按显示器缩放适配并在工作区内自动避让；
10. 九语种界面（简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、俄语）与亮/暗/跟随系统主题；
11. 全局热键冲突自愈：启动注册失败检测、录制式改键、失败自动回退并提示；
12. 本地加密存储 API 密钥（Windows DPAPI），界面不回显明文。
```

## 五、技术特点（申请表单「技术特点」栏，可直接粘贴）

```
1. 采用 Rust + Tauri 2 + Svelte 5 的复合技术架构，在保证系统级能力（全局热键、剪贴板监听、系统 OCR、DPAPI）的同时显著降低内存与安装体积；
2. 截图翻译链路采用"本机识别、仅传文字"的隐私保护设计：截图位图仅在内存中处理，不落盘、不上传，仅识别结果发送至用户配置的服务；
3. 面板几何系统：基于显示器工作区边界的位置记忆与磁吸定位、内容驱动的窗口高度自适应、用户偏好尺寸隔离持久化，适用于多显示器与混合 DPI 环境；
4. 配置单一事实源 + 前端只读镜像的跨进程状态同步机制（settings://changed 广播协议），保证托盘、面板、设置三处状态实时一致；
5. 全局热键的动态注册与自愈：启动批量注册与失败清单、运行期冲突检测、录制式改键与失败回退；
6. 九语种界面与目录化文案体系，语言随系统自动探测并支持运行中切换。
```
